# source-command-migrate-brand-colors

Use this skill when the user asks to run the migrated source command `migrate-brand-colors`.

## Command Template

# STRICT BRAND COLOR MIGRATION — SELECTED SECTION ONLY

I have now replaced my global Tailwind CSS configuration with a new brand color palette based on my company logo.

**Your task is to UPDATE THE COLORS of the currently selected section using my NEW GLOBAL THEME.**

This is a strict color migration, not a redesign.

## 1. Read the existing global theme first

Before modifying anything:

- Locate my global CSS file containing `@import "tailwindcss"`, `@theme`, and `:root`.
- Read all currently defined brand color variables.
- Treat the updated global theme as the ONLY source of truth for brand colors.
- Do not use colors from the previous electric-blue/purple theme.
- Do not introduce new arbitrary colors when a suitable theme token already exists.

## 2. Completely eliminate purple from the selected section

This requirement is mandatory.

Search the selected section's React/JSX/TSX files, CSS files, styled components, and related styles for every source of purple.

Specifically inspect:

- Tailwind classes containing `purple`, `violet`, or `fuchsia`
- Background and text colors
- Gradient start, middle, and end colors
- Hover, focus, active, and disabled states
- Borders, shadows, and box glows
- Inline style objects and CSS custom properties
- GSAP color-related animation properties
- Pseudo-elements such as `::before` and `::after`
- SVG fills, strokes, and gradient stops
- Mobile and responsive styles

Replace all purple styling with the approved blue, silver, or white equivalents.

**Do not assume that updating global variables alone will remove purple.**

Tailwind includes built-in color utilities that can continue displaying purple independently of my custom theme.

Do not leave any purple, violet, or fuchsia colors in the selected section.

Replace old purple-named custom property references with the new semantic silver or blue variables.

## 3. Apply the exact new brand palette

### Backgrounds — 65%

- Main: `#050915`
- Sections: `#08111F`
- Cards: `#0C1B2E`
- Hover surfaces: `#12263D`

### White and Silver — 20%

- Main headings: `#F8FAFC`
- Body text: `#B9C5CE`
- Muted text: `#8297A6`
- Metallic silver accents: `#E2E8F0`

### Metallic Blue — 12%

- Primary blue: `#287FAE`
- Light blue: `#4CB8DF`
- Dark blue: `#18577F`
- Ice blue: `#8BDDED`

Use blue for buttons, icons, interactive elements, active states, subtle glows, and selected heading accents.

### Champagne Gold — 3%

- Gold: `#E8D9BB`
- Light gold: `#FFF4DB`

Gold must be extremely limited and should only appear where it creates a meaningful premium or growth-related detail. Do not automatically add gold to every section.

These percentages apply to the overall website's visual balance, not each individual component.

## 4. Use global CSS variables and Tailwind theme utilities

Prefer existing global tokens rather than hardcoding hex colors.

Examples:

- `var(--primary)`
- `var(--primary-dark)`
- `var(--secondary)`
- `var(--accent)`
- `var(--bg-main)`
- `var(--bg-card)`
- `var(--text-primary)`
- `var(--text-secondary)`
- `var(--border-primary)`
- `var(--gradient-brand)`
- `var(--gradient-metallic)`
- `var(--glow-blue)`

Use the corresponding Tailwind v4 theme utilities wherever appropriate, such as `bg-primary`, `bg-primary-dark`, `text-secondary`, or `border-primary`.

Respect the distinction between CSS variables defined in `:root` and Tailwind utilities generated by `@theme`.

## 5. Preserve my existing website design

DO NOT change:

- Layout
- Structure
- Spacing
- Component sizes
- Font families
- Typography sizes
- Images
- Content
- Button functionality
- GSAP movement or animation timing
- ScrollTrigger behavior
- Responsiveness
- Existing interactions

Only update the visual color styling.

If GSAP currently animates a purple color, replace only that color value. Do not modify the animation behavior.

## 6. Work only on the selected section

Do not modify unrelated sections or pages.

Do not recolor the entire website.

If the selected section uses shared components or global styles, avoid changing them in a way that unintentionally affects other sections.

## 7. Verify the actual rendered result

After implementing the color migration:

1. Search the selected section's relevant source code again for legacy purple, violet, and fuchsia classes, references, and hex values.
2. Check gradients, shadows, pseudo-elements, responsive styles, and animation color properties.
3. Verify that the selected section renders using only the approved brand colors.
4. If browser inspection is available, inspect the computed styles of elements still appearing purple and trace the exact CSS rule responsible.
5. Correct any remaining purple styling.
6. Check that build, syntax, responsiveness, and existing functionality remain intact.

Do not claim the section is purple-free unless the relevant styles have actually been checked.

## Final instruction

**Apply the new Midnight Navy + Metallic Blue + White/Silver + Champagne Gold color theme to the selected section NOW.**

The result must match the colors and professional identity of my shield logo.

No purple. No violet. No fuchsia.

Keep everything else unchanged.

After completing the update, summarize which files and color properties were changed.
